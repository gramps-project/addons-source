# Contribuer

Signaler les anomalies avec les versions Gramps, Python et du système, une description reproductible et, si possible, une généalogie synthétique minimale. Éviter les données personnelles et les médias privés. Fournir les contributions sous GPL v2 avec leur provenance. Accompagner les changements fonctionnels de tests ciblés. Les traductions utilisent les outils gettext du projet Gramps. Le dépôt public sera indiqué lors de la publication.
