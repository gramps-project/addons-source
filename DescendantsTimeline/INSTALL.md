# Installation manuelle

1. Fermer Gramps et conserver une copie d’une éventuelle version précédente hors du dossier plugins.
2. Extraire le ZIP. Placer son unique dossier DescendantsTimeline directement dans le dossier plugins du profil Gramps 6.0, sans imbriquer un second dossier DescendantsTimeline.
3. Relancer Gramps et contrôler la présence de Descendants Timeline dans les graphiques. Commencer avec une généalogie de test.

Emplacements usuels du profil standard

- Windows, %APPDATA%/gramps/gramps60/plugins.
- Linux, ~/.local/share/gramps/gramps60/plugins, selon XDG_DATA_HOME.
- macOS, utiliser le dossier utilisateur de greffons indiqué par la distribution Gramps installée. Ce chemin reste à confirmer sur cette plateforme.

Avec GRAMPSHOME personnalisé, Gramps 6.0 utilise GRAMPSHOME/gramps/gramps60/plugins. Respecter le profil effectivement utilisé.

Pour désinstaller, fermer Gramps puis retirer uniquement le dossier DescendantsTimeline. Pour revenir à la version précédente, remettre la copie conservée au même emplacement. Conserver les généalogies et les autres greffons.
